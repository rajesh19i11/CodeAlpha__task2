# 🤖 My Assistant - A Rule-Based Chatbot

**Task 4: Basic Chatbot | CodeAlpha Python Programming Internship**

A simple **terminal-based rule-driven chatbot** built using Python.  
The chatbot responds to common greetings and questions using predefined keywords and `if-elif-else` logic.

> **Note:** This project does not use Artificial Intelligence or Machine Learning. It is implemented using basic Python rule-based logic.

## 📌 Features

- 🤖 Simple terminal-based chatbot
- 👋 Responds to common greetings
- 😊 Responds to "How are you?" questions
- 🏷️ Tells the user its name
- 💡 Explains what it can do
- 🙏 Responds to thank-you messages
- ❌ Handles empty input
- 🔄 Continuously chats until the user exits
- 👋 Displays a goodbye message
- 🔤 Uses keyword matching for understanding user input

## 🛠️ Technologies Used

- **Python 3**
- `if-elif-else` statements
- Lists
- Functions
- String manipulation
- `any()` function
- `while` loop
- User input
- `time` module
